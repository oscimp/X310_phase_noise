# Phase noise characterization of the B210 output

Various amplitudes of the random generator driving the phase modulator
are selected to drive at 4 MS/s the DACs of the AD9361 around the 200 MHz
carrier, and the resulting phase noise density spectra are recorded by a
Rohde & Schwarz FSWP up to 10 MHz from carrier. 

The phase noise at 10 kHz from carrier is determined, even though the 
40 ms long pseudo-random code generated by the FPGA requires integrating 
from 25 Hz to 2 MHz. Using the best phase noise spectrum when no noise 
is added, the normalized cross correlation is evaluated as

```
octave:> phase_to_var
sigma2 = 4.376853511686193e-06
corratio = 0.999998
```

so well below of 0.2% baseline observed.
